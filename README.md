# vorsorgemitetfs.de

Eigenständige Seite zum Thema „Altersvorsorge mit ETFs: freier Sparplan oder Altersvorsorgedepot?“.
Ein Angebot von Philipp Oelmann, verweist für die Beratung auf justavd.de.

- Next.js als statischer Export (`out/`), Tailwind CSS
- Veröffentlichung über GitHub Pages (`.github/workflows/deploy.yml`), Domain in `public/CNAME`
- Rechenlogik: `src/lib/etf.ts` (Zulagen wie auf justavd.de)

Design bewusst anders als justavd.de: Petrol-Grün statt Orange, DM Sans statt Serifen, Karten statt Linien, Ansprache „du“.

Lokal ansehen: `npm install`, dann `npm run dev` und http://localhost:3000 öffnen.
